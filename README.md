# homebrew-tap

Homebrew tap for Vestin formulae.

## Install

```bash
brew tap vestin-io/tap
brew install vestin-io/tap/so-context
```

To install the development version:

```bash
brew install --HEAD vestin-io/tap/so-context
```

## Layout

- `Formula/so-context.rb`: stable and head formula for `so-context`

## Notes

- This tap currently points at the `vestin-io/so-context` repository.
- If the source repository remains private, installers need GitHub access to that repository.
